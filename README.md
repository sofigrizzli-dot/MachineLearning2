## Данные
В качестве входных данных использовались артефакты из ЛР № 1:
*   `variant_09.tmx` (120 параллельных сегментов EN-RU).
*   `variant_09.tbx` (100 терминов).
*   На основе этих файлов автоматически сгенерированы `segments_en.csv`, `aligned_reference.csv` и `glossary.csv`.

## Исследуемые модели
1.  **Helsinki-NLP/opus-mt-en-ru** (MarianMT): специализированная EN→RU, ~76 млн параметров, словарь 62 518.
2.  **facebook/nllb-200-distilled-600M** (NLLB): многоязычная (200 языков), ~615 млн параметров, словарь 256 204.

## Структура репозитория
*   `data/` — исходные данные и сгенерированные CSV (120 сегментов, 100 терминов).
*   `results/` — файлы с результатами:
    *   `results_marian.jsonl` и `results_nllb.jsonl` — полные переводы корпуса.
    *   `comparison.csv` — сводная таблица сравнения моделей с ручной оценкой (`preferred`, `comment`).
    *   `tokenization_10_terms.csv` — анализ токенизации.
    *   `loss_5_pairs.csv` — кросс-энтропия для 5 пар.
    *   `attention_summary.csv` — сводка по cross-attention.
    *   `timing.csv` — замеры времени инференса.
    *   `glossary_qa.csv` — проверка терминологии.
*   `figures/` — 5 графиков (время, токенизация, loss, внимание, QA).
*   `report.md` — подробный отчет.
*   `requirements.txt` — зависимости (torch, transformers и др.).
*   `Михайловаlab_02.ipynb` — выполненный ноутбук.

## Ключевые результаты
*   **Батчинг:** Пакетный перевод (batch_size=16) оказался в **7.9 раз быстрее** последовательного (3.3 с против 26.4 с).
*   **Токенизация:** Несмотря на больший словарь, NLLB дробит технические термины сильнее (в среднем 3.45 токена), чем MarianMT (2.70 токена).
*   **Терминология:** Найдено 38 потенциальных нарушений. После ручной проверки выяснено, что MarianMT лучше справляется со специфическими терминами (например, "энергосбережение" вместо "сохранность энергии").
*   **Внимание:** Тепловая карта cross-attention подтверждает, что при генерации русских слов модель корректно фокусируется на соответствующих английских токенах.
